# VibePlay AI

MVP для кейса Билайна: сервис превращает естественноязыковой запрос в готовую браузерную HTML5-игру. Основной генератор — GigaChat от Сбера; Gemini и OpenRouter остаются резервом. Результат проверяется на автономность и запускается в изолированном предпросмотре.

## Быстрый запуск

Нужен Node.js 22 или новее (для smoke-теста геймплея используется встроенный WebSocket). Зависимостей у проекта нет.

**Самый быстрый путь на Windows** — запустить `start.bat`: он проверит Node.js, создаст `.env` при первом запуске, поднимет сервер и откроет браузер. Пользовательская инструкция — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Вручную:

1. Скопируйте `.env.example` в `.env`:

   ```powershell
   Copy-Item .env.example .env
   ```

2. Создайте проект GigaChat API в [Sber Developers](https://developers.sber.ru/studio/workspaces/) и вставьте его ключ авторизации в `.env`:

   ```env
   GIGACHAT_AUTH_KEY=ваш_ключ_авторизации
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   GIGACHAT_MODEL=GigaChat-2-Max,GigaChat-2-Pro,GigaChat-2

   # Резервные модели OpenRouter
   OPENROUTER_API_KEY=sk-or-v1-...
   OPENROUTER_MODEL=cohere/north-mini-code:free
   OPENROUTER_FALLBACK_MODEL=nvidia/nemotron-3.5-lightning:free
   OPENROUTER_QA_MODEL=nvidia/nemotron-3.5-lightning:free
   OPENROUTER_QA_BACKUP_MODEL=cohere/north-mini-code:free
   OPENROUTER_FREE_MODEL=openrouter/free
   OPENROUTER_MAX_TOKENS=10000
   MODEL_TIMEOUT_MS=90000
   MAX_REPAIR_ATTEMPTS=1
   PORT=3000
   ```

3. Запустите:

   ```powershell
   npm start
   ```

4. Откройте <http://localhost:3000>.

Ключи читаются только Node-сервером из `.env` и не попадают в браузер. GigaChat автоматически получает и кеширует получасовой access token. Официальный корневой сертификат НУЦ Минцифры лежит в `certs/` и применяется только к соединениям GigaChat — глобальная TLS-проверка не отключается. Для смены основной модели измените `GIGACHAT_MODEL` и перезапустите сервер. При сбое GigaChat сервер переключается на Gemini, Groq, Mistral и бесплатные модели OpenRouter; неработающий маршрут временно исключается.

## Провайдеры и бесплатные лимиты

Основной GigaChat и резервные провайдеры подключаются переменными в `.env`:

| Провайдер | Где взять ключ | Модель по умолчанию | Бесплатный лимит |
|---|---|---|---|
| **GigaChat** | <https://developers.sber.ru/studio/workspaces/> | `GigaChat-2-Max` | freemium для физлиц на 12 месяцев |
| Google AI Studio | <https://aistudio.google.com/apikey> | `models/gemini-3.5-flash,models/gemini-flash-lite-latest` | щедрый дневной лимит |
| Groq | <https://console.groq.com/keys> | `llama-3.3-70b-versatile` | ~14 400 запросов/день |
| Mistral | <https://console.mistral.ai/api-keys> | `mistral-small-latest` | бесплатный тариф |

Порядок попыток при генерации: `GigaChat-2-Max` → `GigaChat-2-Pro` → `GigaChat-2` → Gemini/Groq/Mistral → бесплатные модели OpenRouter → `openrouter/free`. LLM-ремонт запускается только когда локальная статическая проверка или живой smoke-тест нашли дефект.

Freemium GigaChat предназначен только для личного некоммерческого использования. Для коммерческого распространения сгенерированного контента нужен платный пакет.

OpenRouter ограничивает бесплатные модели по числу запросов в сутки. Для надёжного демо лучше иметь запасной прямой ключ Gemini/Groq/Mistral или небольшой баланс OpenRouter. Yandex AI Studio (модели Alice AI LLM) поддерживает API-ключи, но постоянного бесплатного API-тарифа нет, поэтому в бесплатную цепочку он не включён.

## Что показать на демо

1. Ввести: «Замути змейку для бабушки: медленный темп, крупные кнопки и высокий контраст».
2. Нажать «Создать игру» и запустить результат прямо в мобильной рамке.
3. Переключить размеры телефона, планшета и desktop.
4. Внизу попросить: «Сделай кнопки ещё больше и добавь второй уровень».
5. Открыть HTML-код и скачать автономный файл.
6. Перезагрузить страницу: игра останется в локальной галерее.

Если API временно недоступен, кнопка «Демо» открывает готовую автономную игру и позволяет показать предпросмотр, touch-управление и аналитику.

## Архитектура

```text
Промпт пользователя
       ↓
Node API /api/generate
       ↓
системный промпт + GigaChat (резерв: Gemini/OpenRouter)
       ↓
извлечение и проверка HTML
       ↓
sandbox iframe / экспорт одного HTML-файла
```

- `server.js` — статический сервер, безопасный прокси GigaChat/Gemini/OpenRouter, системный промпт со стандартом визуального качества, валидация результата и живой smoke-тест геймплея в headless Chrome.
- `public/app.js` — интерфейс, история в `localStorage`, итерации, экспорт и агрегированная аналитика.
- `public/demo-game.html` — резервная playable-демонстрация, не используемая вместо LLM-генерации.

## Соответствие ТЗ

- Естественноязыковой ввод на русском или другом языке.
- Реальная генерация HTML/JS-кода через GigaChat с автоматическими резервными LLM.
- Системный промпт требует начало, геймплей, победу/поражение и повторный запуск.
- Результат — один HTML без CDN, `fetch`, импортов и серверных зависимостей.
- Touch, клавиатура, адаптивность и WebView учитываются в системном промпте и предпросмотре.
- Итеративная доработка передаёт модели текущий HTML и новую просьбу.
- История и галерея хранятся локально, игру можно скачать.
- События `start`, `win`, `lose`, `restart` собираются локально и агрегировано учитываются при следующих генерациях.
- Жанр не зашит: механику и визуальный стиль каждый раз создаёт модель по запросу.

## Проверка

```powershell
npm run check
```

Проверка реальной генерации требует хотя бы одного действующего ключа GigaChat, Gemini, OpenRouter, Groq или Mistral. Встроенное демо работает без ключа.

## WebView

Скачанный файл можно открыть через `file://`, Android `WebView.loadUrl(...)` или iOS `WKWebView.loadFileURL(...)`. В игре нет обращения к API: GigaChat и резервные LLM нужны только на этапе генерации.

Для продакшена потребуется добавить авторизацию, rate limit, серверное хранилище и более строгую песочницу. Для хакатонного MVP они намеренно не усложняют основной сценарий.
